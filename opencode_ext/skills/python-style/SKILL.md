# Стиль Python-кода

- Python 3.12, аннотации типов у всех параметров и возвращаемых значений.
- У каждой функции docstring на русском: что делает и что возвращает.
- Только стандартная библиотека, без сторонних пакетов.
- Без print в коде модуля: функции возвращают значения.
